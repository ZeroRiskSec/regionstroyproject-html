\# RegionStroyProjectHTML



Генератор HTML-страницы с информацией об ООО «Регионстройпроект».

Кейс-задача № 5 практики.



\## Что делает программа

\- Генерирует `index.html` с заголовком «ООО «Регионстройпроект»»

\- Выводит таблицу с реквизитами организации

\- Применяет основной шрифт компании (Arial) ко всей странице

\- Демонстрирует 5 альтернативных шрифтов: Times New Roman, Georgia,

&#x20; Verdana, Trebuchet MS, Courier New



\## Запуск

```bash

python generate.py

```

Затем откройте `index.html` в браузере.



\## Требования

\- Python 3.8+
